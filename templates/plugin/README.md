# Plugin template

Copy this directory to `plugins/<plugin-name>/`, replace the manifest metadata, and replace this README with the plugin documentation. This template is not listed in the marketplace.

Document the plugin's purpose, included skills, when to use each skill, required tools or connections, setup, and example requests. Link each skill's `SKILL.md`.

Replace the example skill with a complete workflow before listing the plugin. Keep supporting files inside the plugin directory. Preserve imported licenses and attribution and record provenance in the root README.
